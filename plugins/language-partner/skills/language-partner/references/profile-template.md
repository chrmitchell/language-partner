# Learner profile template

Save the profile as plain text with exactly these headings, in this order, so later chats can find and update each part. Keep the whole profile under about 6000 characters. Short lines, no long prose.

```
# Learner profile: <language name>

## About me
Name: <name>. Introduces themself as: <name in target language, if different>.
Native language(s): <...>. Other languages: <...>.

## Goals
<Why they're learning, with any dates. One or two lines.>

## Situations that matter
<Comma-separated list, most important first.>

## Level
<Overall level in plain words, for listening and for speaking. What they can do, what's hard.>

## Solid
<Words, phrases and structures they handle well. Comma-separated.>

## Shaky
<Recurring mistakes and things they're still working on. Comma-separated.>

## Preferences
Corrections: <e.g. only errors that cause confusion, recasts first>.
English: <e.g. allowed any time, keep asides short>.
Mode: <e.g. usually voice mode>.
Other: <e.g. romanisation wanted, topics to avoid, speed>.

## Session log
<YYYY-MM-DD: one line on what was practised and what stood out. Newest last.>
```

## Rules

- Always read the latest profile, edit it, and write back the full text. The tool replaces the whole profile.
- Fill in only what the learner told you or what you clearly observed. Write "Not known yet" instead of guessing.
- Keep one line per session in the Session log. When the profile gets close to the limit, delete the oldest log lines first, after folding anything lasting into Level, Solid or Shaky.
- Learner requests about how practice works go under Preferences, and they override this skill's defaults.
